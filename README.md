# MAX × МИЭМ НИУ ВШЭ — каталог вакансий и компетенции ОП

Статический сайт: 26 открытых вакансий проекта MAX, связанных с дисциплинами образовательной
программы «Информатика и вычислительная техника» (МИЭМ им. А. Н. Тихонова, НИУ ВШЭ).

Сайт не требует сервера и сборки на хостинге: это набор HTML/CSS/JS, все ссылки относительные,
поэтому он одинаково открывается и локально, и на GitLab Pages.

## Структура репозитория

| Путь | Назначение |
| --- | --- |
| `site/index.html` | главная страница: о компании, путь сообщения, 8 предметов-приоритетов, сетка вакансий, контакты |
| `site/spec/*.html` | 26 страниц вакансий: задачи, требования, стек, компетенции ОП, рост |
| `site/all.html` | весь сайт одной страницей (удобно для офлайн-показа и печати) |
| `site/assets/` | `style.css`, `app.js`, логотип |
| `data.py` | исходные данные: компания, программа, 8 предметов, 26 вакансий |
| `build2.py` | генератор статики из `data.py` |
| `assets/` | исходники `style.css` / `app.js` и картинки (копируются в `site/assets/`) |
| `.gitlab-ci.yml` | публикация `site/` на GitLab Pages |

## Локальный просмотр

Открыть `site/index.html` в браузере (двойным кликом) — этого достаточно.

Либо поднять локальный сервер:

```bash
python3 -m http.server -d site 8000
# http://localhost:8000
```

## Пересборка сайта

```bash
python3 build2.py
```

> Внимание: `build2.py` полностью перезаписывает папку `site/`. Часть правок в `site/` сделана
> вручную (ссылки в шапке, блок «Дисциплины программы, которые работают на эту вакансию»,
> подписи к вакансиям), поэтому перед пересборкой сверьтесь с предупреждением в шапке `build2.py`.

## Публикация (GitLab Pages)

`.gitlab-ci.yml` при пуше в ветку по умолчанию копирует `site/` в артефакт `public/`, который
раздаёт GitLab Pages.

```bash
git remote add origin git@git.miem.hse.ru:<namespace>/<проект>.git
git push -u origin main
```

Дальше: **CI/CD → Pipelines** (джоба `pages` должна быть зелёной) и **Deploy → Pages** — там будет
итоговый адрес сайта. Для приватного проекта доступ к странице выдаётся в **Deploy → Pages →
Access control**, а преподавателя нужно добавить в **Manage → Members**.

Если на инстансе не включены shared runners или сам GitLab Pages, сайт всё равно можно сдать:
репозиторий скачивается через **Code → Download source code**, после чего открывается
`site/index.html`.

## Связка «дисциплина → вакансия»

Восемь предметов-приоритетов и их навыки взяты из внутренней презентации по подготовке к MAX:

1. Алгоритмизация и программирование, 1 курс — C/C++, алгоритмы, чтение кода, Git, отладка и тесты
2. Проекты и индустриальные практики, 1–4 курсы — командная работа, коммуникация, применение знаний, портфолио
3. Базы данных, 2 курс — SQL, проектирование БД, транзакции и запросы
4. Объектно-ориентированное программирование, 2 курс — структура программы, проектирование и поддержка кода
5. Вычислительные системы и компьютерные сети, 3 курс — сети, протоколы, основа сетевых взаимодействий
6. Операционные системы, 3 курс — процессы, ресурсы, основа администрирования
7. Python в науке о данных, 1 курс — программирование для обработки данных
8. Проектная документация, 2 курс — описание решений, инструкции, передача информации

У каждой вакансии в блоке «Какие компетенции ОП МИЭМ на это работают» указаны 2 предмета из этого
списка; на главной у каждого предмета, наоборот, перечислены вакансии, на которые он работает.
